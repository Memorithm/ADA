# ADA Agent Bootstrap Contract

Before autonomous coding, candidate-semantic changes, evidence-rule changes, FLAT/TDI/ITD/Forge integration, adoption/novelty decisions, PR creation, or merge decisions, read:

```bash
git fetch origin agent/ecosystem-roadmap && \
git show origin/agent/ecosystem-roadmap:.agent/ADA_ECOSYSTEM_ROADMAP.yaml
```

If the roadmap cannot be fetched or read, fail closed for major semantic-adoption, novelty, cross-repository promotion, or merge decisions. Read-only diagnosis is allowed.

ADA is an attention algorithm discovery/falsification bench, not a production attention runtime. Preserve the qualification ladder: generate → prove/falsify → independent oracle → adversarial tests → cost → real-hardware benchmark when relevant → adopt/adapt/reject. A potential novelty claim additionally requires prior-art review.

FLAT-ATTENTION owns production execution and GPU promotion. TDI/ITD may provide supporting mechanistic evidence. Forge may provide generic search machinery after attention semantics and invariants are frozen. None of these replaces ADA's semantic correctness gates.

Logical operation counts are not physical performance claims. Required CI must be green on the exact PR head before merge.

Reread the roadmap at every session start, before semantic/evidence changes, before ecosystem integrations, and before adoption, novelty, PR or merge decisions.

Do not merge the roadmap itself into `main` unless the user explicitly requests it.
